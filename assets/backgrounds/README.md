# Tes vidéos de fond

Dépose ici tes propres vidéos (`.mp4`, `.mov`, `.m4v`, `.webm`) : ciel, pluie, mer, forêt…

- Uniquement des vidéos à toi ou libres de droits ([Pixabay](https://pixabay.com/fr/videos/), [Pexels](https://www.pexels.com/fr-fr/videos/)).
- Pas de personnes, et jamais de représentation des prophètes ni des compagnons. Rien d'inapproprié à côté du Coran.
- Verticales de préférence ; sinon le moteur recadre en 9:16. Trop courtes ? Elles sont bouclées.
- Ce dossier n'est pas envoyé sur GitHub (fichiers lourds).

Utilisation : `npm run video -- --passage raad-28 --bg random` (une de tes vidéos au hasard) ou `--bg assets/backgrounds/pluie.mp4`.
